This project uses the osmnx, matplotlib, shapely and vsketch packages to create a customized map of Pavia, Italy from OpenStreetMap. The osmnx package is used to access and download OpenStreetMap data for **Pavia, Italy**.

The matplotlib package is used to render the downloaded data as a map. The shapely package is used to process the downloaded data into the appropriate format.

Finally, the vsketch package is used to create a customized map with various features, such as streets, buildings, parks, and landmarks. The resulting map provides a detailed overview of Pavia, Italy.
