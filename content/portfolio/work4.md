This project seeks to provide an interactive and informative visualization of the global GDP growth rate from 1961-2017 and the GDP by country in 2017. The Tableau dashboard created for this project will allow users to explore the data in an interactive manner, with charts and tables that can be filtered and manipulated to suit the user’s needs. 

The dashboard will include a visualization of the global GDP growth rate from 1961-2017, allowing users to see how the global economy has grown and changed over time. Additionally, the dashboard will include a visualization of the GDP by country in 2017, allowing users to compare the GDP of different countries and gain insights into the economic health of each nation. 

Using the [Tableau dashboard link](https://public.tableau.com/views/GDPbyCountry2017/GDP2017byCountry?:language=en-US&:display_count=n&:origin=viz_share_link), Users can explore the data further.
