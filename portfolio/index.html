Paddy Field Mapping using NDVI Thresholding and Machine Learning

Links:

In this project, I developed a comprehensive methodology for accurate and efficient mapping of paddy fields in the Nalgonda District, India, using multi-temporal Sentinel-2 imagery. The study employed three approaches: NDVI thresholding, Random Forest classification, and Support Vector Machine (SVM) classification. The research focused on the Rabi season from December 2019 to May 2020, analyzing the unique phenological patterns of paddy growth to improve classification accuracy.

Breast Cancer Prediction with Machine Learning Algorithms

Breast cancer is one of the most common forms of cancer among women worldwide. Early detection and accurate diagnosis of breast cancer are crucial for effective treatment and recovery. In this project, my aim is to develop a machine learning model that can predict the diagnosis of breast cancer using different algorithms.

The project is done in Google Colab using libraries such as:

  • numpy
  • pandas
  • matplotlib
  • seaborn

Dataset Summary

The dataset contains 569 samples of breast cancer tumors and 30 features. The dataset is divided into two classes: malignant (cancerous) and benign (non-cancerous) tumors. The dataset is loaded into the program using the pandas library.

Stock Price Prediction using Python and the LSTM Machine Learning Model

In this project, I used Python and the LSTM machine learning model to predict the stock price of TSLA (Tesla, Inc.). We start by importing the necessary libraries and creating a Ticker object for TSLA. Then visualized the closing price and create a new data frame with only the close column. This data frame is converted to a numpy array and scaled using a MinMaxScaler.

Data is split into training and testing datasets, which are then converted to numpy arrays. An LSTM model is built and compiled, and is then trained on the training data.

GDP by Country 2017 Tableau

This project seeks to provide an interactive and informative visualization of the global GDP growth rate from 1961-2017 and the GDP by country in 2017. Prettymaps The Grand Canal in Venice, Italy

This project uses the osmnx, matplotlib, shapely and vsketch packages to create a customized map of Pavia, Italy from OpenStreetMap. The osmnx package is used to access and download OpenStreetMap data for The Grand Canal in Venice, Italy.

The matplotlib package is used to render the downloaded data as a map. The shapely package is used to process the downloaded data into the appropriate format.

Finally, the vsketch package is used to create a customized map with various features, such as streets, buildings, parks, and landmarks. The resulting map provides a detailed overview of The Grand Canal in Venice, Italy.
